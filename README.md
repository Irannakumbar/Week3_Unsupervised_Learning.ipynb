# Week 3: Unsupervised Learning & Model Evaluation

## Overview
This project explores clustering, dimensionality reduction, classification, and model evaluation using the Iris dataset.

## Techniques Used
- K-Means Clustering
- Hierarchical Clustering
- Principal Component Analysis (PCA)
- Logistic Regression
- Confusion Matrix and Classification Report
- ROC-AUC Evaluation
- Five-Fold Cross-Validation
- GridSearchCV Hyperparameter Tuning
- Silhouette Score and Adjusted Rand Index

## Tools and Libraries
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib
- Scikit-learn

## Files
- `Week3_Unsupervised_Learning.ipynb` — notebook containing code, results, and visualizations.
- `Week3_Report.docx` — project report.

## Dataset
The Iris dataset provided by Scikit-learn.
